## Raspi
Aqui solo necesitaremos que se ejecute localStack
Entonces podemos hacerlo de 2 formas usando curl o pipx
recomiendo pipx, pero yo lo hice por curl. la raspi es ARM entonces eligo este enlace(buscar el enlace actualizado):
``` bash
curl --output localstack-cli-2026.6.0-linux-arm64-onefile.tar.gz \
    --location https://github.com/localstack/localstack-cli/releases/download/v2026.6.0/localstack-cli-2026.6.0-linux-arm64-onefile.tar.gz
```
Despues ese archivo debemos descomprilo en ~/.local/bin/
``` bash
tar -xzf localstack-cli-2026.6.0-linux-arm64-onefile.tar.gz -C ~/.local/bin 
rm localstack.tar.gz
```
Aseguramos definir 
``` bash
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc
source ~/.bashrc
```

### Inicar localStack
``` bash
localstack start -d
```
yo tuve el incoveniente de tener ocupado el puerto 433 y tuve que usar este comando para cambiar de puerto

```bash
echo 'export GATEWAY_LISTEN=:4566' >> ~/.bashrc 
source ~/.bashrc 
localstack start -d
```
En mi caso como lo tengo en una raspi pondre esto:
```bash
echo 'export GATEWAY_LISTEN=0.0.0.0:4566' >> ~/.bashrc
source ~/.bashrc
localstack start -d
```

## Laptop (desarrollo)
Bueno aqui vamos a conectarnos mediante el cliente de aws, bueno es especifico aws-local
Pero primero necesitamos descargar awscli
``` bash
curl "https://awscli.amazonaws.com/awscli-exe-linux-x86_64.zip" -o "awscliv2.zip"
unzip awscliv2.zip
sudo ./aws/install
```
y ahora instalamos aws-local
```bash
# Primero instalamos pipx
sudo apt update
sudo apt install -y pipx
pipx ensurepath

# Despues instalamos aws-local
pipx install awscli-local
```
Para probar sin cerrar la terminal
```bash
source ~/.bashrc # o zsh
```

### Probarlo
Ahora para probarlo solo necesitas usar awslocal como si fuera la api de aws Ejemplo:
```bash
awslocal --endpoint-url=http://192.168.100.11:4566 s3 mb s3://mi-bucket-de-prueba
```

Para evitar poner poner todo eso de **--endpoint-url=** podemos crear un alias en ~/.zshrc
```
alias aws-pi="awslocal --endpoint-url=http://192.168.100.11:4566"
```
Puedes ver como modificar usar la api de awslocal o en este caso aws-pi S3 puedes verlo aqui [[AWS/LocalStack/02.LocalStack S3\|02.LocalStack S3]]
